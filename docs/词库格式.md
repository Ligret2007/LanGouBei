# 词库文件格式

LangoBei 的词库就是一个 JSON 文件。内置词库、你导入的词库、导出的词库都用同一套格式，
所以「导出 → 改 → 再导入」能走通，也可以拿 Excel、脚本或 AI 生成一份。

## 最小可用

```json
{
  "words": [
    { "word": "abandon", "meaning": "v. 放弃；抛弃" }
  ]
}
```

只有 `word` 是必填的，其余都能省。

## 顶层字段

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| `format` | string | 固定写 `langobei-bank`。可以不写，写了就必须对 |
| `formatVersion` | int | 格式版本，目前是 `1`。比 App 新的版本会被拒绝，免得读出错词 |
| `id` | string | 词库标识，建议只用小写字母、数字、`-`、`_`；与已有词库重名时导入会自动改名 |
| `name` | string | 界面上显示的名字。不写就用文件名 |
| `subtitle` / `description` / `author` / `version` | string | 展示用的补充信息，都可省 |
| `words` | array | **必填**，单词列表，不能为空 |

## 单个单词

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| `word` | string | **必填**，单词或短语 |
| `phonetic` | string | 音标，例 `\/əˈbændən\/` |
| `pos` | string | 词性，例 `v.` |
| `meaning` | string | 释义 |
| `level` | string | 难度：`easy` / `normal` / `hard` / `extra`，写错或不写按 `normal` |
| `tier` | string | 属于哪一档。内置词库用 `core` 表示「菜鸟」，没标 `core` 的词只在「大神」里出现；自己导入的库忽略这个字段 |

`id` 可以不写，App 会从 `word` 算一个稳定的 id（全小写、空格换成 `-`）。
学习进度按这个 id 存，所以**同一个单词在不同词库里共享进度**——改 id 等于换了个新词。

## 怎么导入

「更多 → 词库 → 导入词库」：

- **从文件选择**：选一个 `.json` 文件读进来
- **粘贴 JSON**：把文本贴进去，适合从聊天窗口或笔记里搬

导入成功后会自动切到新词库。文件存在 App 私有目录里，不需要存储权限，卸载即清除。
每个库右侧的「⋯」可以**导出为文件**（落到系统「下载」目录）、**复制 JSON**、**删除**（内置库不能删）。

重复的单词会合并、认不出的记录会跳过并给出提示，不会让整份导入失败。

## 内置词库的装配方式

`assets/words_gaokao.json` 装了 3540 个高考词，`assets/banks/index.json` 把它拆成两个可选的库：

```json
{
  "format": "langobei-bank-index",
  "banks": [
    { "id": "core", "name": "高考：我是菜鸟", "asset": "assets/words_gaokao.json", "tier": "core", "wordCount": 3014 },
    { "id": "ext", "name": "高考：我是大神", "asset": "assets/words_gaokao.json", "wordCount": 3540 }
  ]
}
```

想加一个随包词库：把 JSON 放进 `assets/`，在 `index.json` 里加一条，再到 `pubspec.yaml` 的 `assets:` 里登记，不用改 Dart 代码。
